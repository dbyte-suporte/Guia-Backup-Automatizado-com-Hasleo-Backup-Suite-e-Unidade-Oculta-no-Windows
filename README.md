# Guia-Backup-Automatizado-com-Hasleo-Backup-Suite-e-Unidade-Oculta-no-Windows
Este guia ensina a configurar backups automáticos do sistema utilizando o Hasleo Backup Suite Free e a proteger a unidade de destino ocultando a sua letra no Explorador de Arquivos do Windows. Isso impede acessos acidentais por parte dos usuários sem interromper a rotina de backup.
